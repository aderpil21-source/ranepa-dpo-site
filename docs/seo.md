# SEO сайта

Метаданные всех публичных HTML-страниц находятся в исходном HTML: title,
description, robots, Open Graph, Twitter Card и canonical. Авторизация VK и
фоновый плеер имеют noindex. Платёжная страница сохраняет CSP script-src 'none'
и не содержит скриптов.

## Обновление

Тексты разделов редактируются в `scripts/generate_seo.py` (PAGES), затем:

```sh
python scripts/generate_seo.py
python scripts/generate_seo.py --check
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/program-seo.test.cjs
```

Sitemap включает публичные разделы и активные программы из обоих локальных
источников с учётом site-settings.json. Существующие задания обновления данных
перегенерируют sitemap. После ручного изменения данных также запускайте генератор.
lastmod не выдумывается: дата запуска генератора не означает изменение контента.

## Страницы программ и границы реализации

Существующий маршрут `program.html?id=...` сохранён. `program-seo.js` создаёт
canonical с ID, исключая рекламные и языковые параметры. Вызов из render()
обновляет description, социальные теги и Course JSON-LD из тех же полей,
которые видит посетитель. При отсутствии/скрытии программы добавляется noindex.
Переключение языка обновляет метаданные, canonical остаётся на основной русской
версии. Отдельная индексация переводов и hreflang не вводятся.

Сайт статический, без сборщика. Индивидуальные метаданные программ требуют
JavaScript; роботы социальных сетей могут видеть общие теги шаблона. Для
индивидуальных превью без JS нужны пререндеринг или серверная генерация HTML.
Новости открываются через #id внутри news.html: это один индексируемый URL.
Разделы главной страницы с #якорями также не являются отдельными документами.
Отдельные URL новостей/пререндеринг требуют самостоятельного изменения маршрутизации.

После публикации проверьте доступность robots.txt и sitemap.xml на рабочем
домене, отправьте sitemap в Яндекс Вебмастер и Google Search Console. Метатеги
не гарантируют позиции в поиске; поисковик может самостоятельно выбрать сниппет.

Источники: https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics
и https://developers.google.com/search/docs/appearance/snippet.
