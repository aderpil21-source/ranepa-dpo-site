Получение USER-токена VK

Этот технический экран запрашивает пользовательский токен VK с правами photos, wall, groups для загрузки изображений в посты.

Токен никуда не отправляется: он показывается только в этом браузере. Не присылай его в чат и не делай скриншот с открытым значением.

Токен получен. Скопируй его сразу в GitHub Secret VK_UPLOAD_TOKEN.
